# Diseño visual y justificación

## Patrón de lectura Z/F
La página principal se organiza para una lectura ejecutiva:

**1. Arriba:** KPI principales.  
**2. Segunda franja:** evolución temporal + comparación regional.  
**3. Tercera franja:** segmentación por segmento + canal.  
**4. Abajo:** tabla para profundización.

El recorrido esperado es:

**Resultado → evidencia → segmentación → detalle.**

## Color
El color tiene función de diferenciación y jerarquía:
- Categorías distintas se diferencian mediante colores consistentes.
- No se utilizan colores decorativos sin propósito analítico.
- Las alertas o situaciones críticas deben explicarse también mediante magnitud y texto, no
  depender exclusivamente del color.

## Gráficos
- Línea: evolución temporal.
- Barras horizontales: ranking regional.
- Barras verticales: comparación de segmentos/canales.
- Dispersión: relación volumen-margen y entrega-satisfacción.
- Tablas: detalle que no debe competir visualmente con los KPI.

## Interactividad
Los filtros de fecha, región, segmento, canal y tipo de cliente actualizan todos los indicadores
y visualizaciones.

Esto permite demostrar durante la sustentación que cada interacción tiene un propósito analítico.
